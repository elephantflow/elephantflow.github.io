>
> 第二条主线是**世界动作模型（WAM）正在摆脱对大生成骨干的依赖，转而追求可实时闭环**。Agile-WAM 的切入点很准：现有触觉 WAM 靠大规模预训练生成骨干来捕捉接触动力学，代价是推理慢、部署重；它改用 ResNet-18 视觉编码器 + 从零训练的触觉 ResNet-18 + 轻量 MLP 速度场，把视觉与触觉编码进共享潜空间，直接做 vision-tactile-to-action 的 flow matching，并针对「视觉帧间高度相似、触觉在接触瞬间突变」这一时间尺度差异做多视界预测（视觉潜变量在更大时间偏移上监督，触觉潜变量只预测下一帧）。结果是真机五任务相对最强基线 **+29.4%**，推理延迟 **11.9 ms**。
>
> 第三条主线是**生成模型正在成为数据放大器而非替代品**。ReShoot 的立场很务实：它不生成新动作，而是把已录制演示「重渲染」一遍——VLM 给场景打字幕并改写单一属性（背景、物体颜色或材质），边缘条件视频生成器（Wan2.2-T2V-A14B + ControlNet HED）同时重画第三人称与腕部两个视角，超分恢复锐度，VLM 再改写指令；**动作与本体感受完全沿用原录制**。于是「换一个外观」从一次采集变成一次生成。真机上的效果最说明问题：换色物体上，仅用录制数据训练的策略成功率是 **0.0%**，加入重渲染数据后升到 **42.9%（43 条演示）与 47.5%（100 条演示）**，而原外观下的性能不掉。

### Towards High-DoF Dexterous Manipulation through VLA Post-Training

**链接：** https://arxiv.org/abs/2609.19666

**项目主页：** https://wuji.tech/blog/post-training-0

**作者 / 机构：** Junlei Zhu, Shenzhe Yao, Chaogui Huang, Wenkai Zhu, Jingwei Peng, Guanqi He, Sören Schwertfeger, Jiahao Chen, Yide Liu（无界智慧 Wuji Technology；上海科技大学信息科学与技术学院）

**一句话总结：** 无界智慧与上海科技大学团队给出一套把开源 VLA 基座后训练成**高自由度灵巧手**策略的四步流水线——学习式手部动作编解码器 → 监督微调 → 人类门控 DAgger → 真机潜空间残差 RL，在五个真实灵巧操作任务上每个任务 20 次试验**全部成功**。

**研究问题：** 模仿学习得到的 VLA 基座模型靠跨任务、跨本体数据获得了广谱操作能力，但落到具体任务与具体硬件上仍需后训练。灵巧手让这一步格外困难：行为空间大、自由度高，带来三个硬障碍——① 开源 VLA 原生不提供高自由度手的动作接口；② 人类接管（DAgger）时手势不匹配会造成指令跳变，并污染纠正轨迹；③ 在原始关节空间做强化学习样本效率极低。核心问题是：**如何设计一条统一接口，让 SFT、纠正数据聚合与真机 RL 三个阶段能在同一个动作表示上接力？**

**核心方法：** ①**学习式时序手部动作编解码器（Step 1）**：用 chunk 级变分 Transformer 把整段手部动作块压缩为潜变量，每只手 9 维，两只手 2×7 + 2×9 = 32 维——恰好是预训练 π0.5 checkpoint 能接受的最大动作维度，因此无需改动基座动作头；对比 PCA、逐帧 MLP / Transformer VAE、chunk 级 MLP，chunk 级变分 Transformer 重建误差最低。②**监督微调（Step 2）**：从公开 π0.5 checkpoint 出发，在潜动作空间微调。③**人类门控 DAgger（Step 3）**：接管时从「失败前的缓存状态」给出恢复轨迹，并做平滑指令混合以消除指令跳变。④**潜空间残差 RL（Step 4）**：把探索限制在编解码器学到的协调手部动作流形上，避免在原始 54 维关节空间盲目搜索。

**技术亮点：**
- **用「动作维度上限」反推潜变量宽度**：选择 9 维/手不是靠调参，而是由「2×7 + 2×9 = 32 恰为 π0.5 接受上限」这一硬约束与重建精度共同决定，工程上极具可复制性。
- **DAgger 比加演示更省样本**：在 250 与 300 两条累计 episode 预算上，DAgger 流水线的成功率都高于「同预算的纯演示」——额外演示独立于当前策略采集，无法适配其不断变化的失效模式，而 DAgger 用当前策略的 rollout 定位需要纠正的位置。
- **探索空间从 54 维压到 18 维**：潜空间残差 RL 把探索约束在编解码器捕获的协调手部动作上，这是真机 RL 能跑通的关键。
- **评测设置诚实**：Rotate Marker in Hand 不接受纠正，直接从 SFT 进入在线 RL；每个 checkpoint 独立评 20 次试验。

**实验结果：** 平台为双臂 **2×7-DoF 天机机械臂 + 2×20-DoF 无界灵巧手**，头部 RGB + 双侧腕部 RGB，遥操作用手套与 Vive Tracker，关节位置控制 30 Hz，单帧指令变化限幅 π/18 rad。五个任务为 Pick Up Marker、Transfer Marker between Hands、Rotate Marker in Hand、Remove Marker Cap、Write on Paper，覆盖抓取、双手传递、手内重定向、物体分离与接触丰富的书写。**最终策略在全部五个任务上均取得 20/20（100%）成功率**；论文同时给出每个阶段 checkpoint 的成功率曲线，展示 SFT → DAgger → 残差 RL 的逐级提升。

**应用场景：** 高自由度灵巧手的真实产线/实验室操作（装配、移液、工具使用）；需要把通用 VLA 基座适配到特定硬件的团队；真机 RL 资源有限、需要靠结构化动作表示降低探索成本的场景。

**研究价值：** ⭐⭐⭐⭐（4/5）— 这是一篇少见的「把整条后训练链路讲透」的论文：动作接口怎么定、接管数据怎么不污染、真机 RL 怎么限制探索，都有明确答案和消融。29 页正文 + 五个真机任务 100% 的完成度，对任何想做灵巧手落地的团队都是直接可复用的工程范本。唯一遗憾是缺乏与同类灵巧手 VLA 的横向对比，主要是对自身流水线的纵向验证。

### MaskHarness-WAM: Instance-Grounded Harnessing for Long-Horizon Robot Manipulation

**链接：** https://arxiv.org/abs/2609.19974

**作者 / 机构：** Zitai Huang, Taiyi Su, Jian Zhu, Jianjun Zhang, Chong Ma, Tianbin Liu, Weiyi Lu, Yi Xu, Hanli Wang（同济大学 AIRC、美的集团 Midea Group）

**一句话总结：** 同济 AIRC 与美的团队提出 **MaskHarness-WAM**，用**目标掩码**把高层任务规划与底层世界动作模型（WAM）接起来：harness 负责拆子任务、维护目标实例身份、执行前验证掩码、确认完成后才推进，从而在「多个外观完全相同、必须按序操作」的长程任务上大幅超越有限视界策略。

**研究问题：** 工业装配、仓储分拣、实验室自动化里经常出现这样一类任务：多个外观完全一致的物体必须按指定顺序操作（相同的螺丝依次拧入不同的孔、视觉上无法区分的试管按样本编号依次转移）。这类物体的身份只能靠空间关系（「最左边那个」「从左数第三个」）来指定。有限视界的 VLA / WAM 策略既没有显式实例身份，也不跟踪任务状态，于是会出现选错目标、重复操作或过早切换阶段。核心问题是：**如何在不重新设计底层策略的前提下，为它持续提供经过验证的实例级目标条件与可靠的阶段推进信号？**

**核心方法：** ①**掩码条件化的 WAM 作为底层执行原语**：输入多视角 RGB、本体感受、局部操作指令与**目标掩码**，输出有限视界的双臂动作块（H = 32，每步 14 维 = 双臂各 7-DoF）；RGB 与目标掩码经同一个 VAE 编码后在通道维拼接，掩码只加在提供全局稳定视角的头部视图上。②**任务级 harness 闭环**：把长程指令分解为有序子任务，维护「当前目标实例」与「已完成集合」。③**执行前掩码验证 + 完成后才推进**：每个子任务对应不同目标实例，每次执行前先核验掩码，只有在完成状态被确认后才切换到下一个实例。④**视觉反馈驱动的子任务调度**，使同一套底层策略可以被跨长程任务复用。

**技术亮点：**
- **明确把问题定义为「外挂层」而非「模型能力」**：论文清楚指出它不改变 WAM 的架构或训练目标，而是解决 harness 如何在长程执行中验证、维护与更新视觉条件——这是一个可迁移到任何底层策略的思路。
- **用「未见过执行顺序」做泛化评测**：训练集只含 4 实例演示，其中方块覆盖 18 种顺序、试管 15 种，其余顺序留作评测；测试时评 3/4/5 实例共 6 个设置，3 与 5 实例用于检验对未见任务规模与视界的泛化，4 实例保持规模不变但用未见顺序检验组合泛化。
- **还评了外观、场景构成、几何的 distribution shift 与零样本跨类别迁移**。
- 训练用连续 flow matching 目标，1000 个流匹配时间步。

**实验结果：** 真机平台为 **ARX 双臂 7-DoF**，两个序列操作任务（方块、试管），每个设置 **25 次独立试验**。SR / PR（PR = 最长正确前缀占比）如下：方块三实例 **88.0 / 93.3**、四实例 **84.0 / 92.0**、五实例 **84.0 / 91.2**；试管三实例 **96.0 / 97.3**、四实例 **88.0 / 94.0**、五实例 **88.0 / 96.0**。对比基线中方块任务 π0 为 20.0/32.0、28.0/32.0、0.0/8.8，Fast-WAM 为 24.0/28.0、12.0/16.0、0.0/4.0，MaskWAM 为 56.0/72.0、8.0/31.0、4.0/23.2。**全部六个设置上 SR 与 PR 均为最高，主要设置 SR 不低于 84%**。

**应用场景：** 相同外观物体的按序装配与分拣；需要跨多个子任务持续跟踪「做到哪一步」的长程操作；已有底层 WAM/VLA 但缺乏任务级状态管理的系统。

**研究价值：** ⭐⭐⭐⭐（4/5）— 在「多个一模一样的物体按顺序操作」这个真实却长期被回避的场景上给出了干净的解法与扎实的真机数据。84–96% 对比 π0 最高 28% 的差距说明，**长程任务的瓶颈往往不在底层控制的精度，而在目标身份与进度的显式管理**。由于它是一层外挂，迁移成本极低。

### Agile-WAM: An Agile Tactile World Action Model for Contact-Rich Robot Control

**链接：** https://arxiv.org/abs/2609.20761

**项目主页：** https://hanchuzhou.github.io/TARO_project_page/

**作者 / 机构：** Hanchu Zhou, Dechen Gao, Boqi Zhao, Junshan Zhang（University of California, Davis）；Brendan Lynch, Raman Goyal, Begum Kasap（Analog Devices, San Jose）

**一句话总结：** UC Davis 与 Analog Devices 团队提出 **Agile-WAM**，一个「轻装上阵」的触觉世界动作模型：用两个 ResNet-18 分别编码视觉与触觉，在共享潜空间上直接做 vision-tactile-to-action 的 flow matching，联合生成动作块与未来视觉/触觉潜变量，把推理延迟压到 **11.9 ms**，真机五任务相对最强基线 **+29.4%**。

**研究问题：** 世界动作模型通过联合预测未来世界状态与机器人动作，让策略学到支撑控制的物理动力学，比传统视运动策略更进一步。但接触丰富的操作仅靠视觉观察不全——视觉上几乎相同的观测可能对应截然不同的物理状态（末端以不同力度接触刚体）。近期触觉 WAM 的做法是给大规模预训练生成骨干加上触觉观测与动作，代价是**推理效率低、部署不灵活**。核心问题是：**能否在去掉大生成骨干的前提下，仍然显式建模触觉的未来演化，从而同时拿到精度与实时性？**

**核心方法：** ①**共享潜空间的双模态编码**：ImageNet 预训练 ResNet-18 作视觉编码器；由于 TacFF 触觉信号具有类图像的空间结构，另用一个从零训练的 ResNet-18 作触觉编码器。②**直接的 vision-tactile-to-action flow matching**：共享潜变量作为 flow matching 过程的源，联合生成动作块潜表示与未来视觉/触觉潜变量；速度场用轻量 MLP 参数化，推理时显式 Euler 求解器仅需 **6 步**。③**多视界多模态预测（核心洞察）**：视觉与触觉在本质不同的时间尺度上演变——相邻视觉帧往往高度相似，而触觉信号在接触瞬间可能突变。因此**在更大的时间偏移上监督视觉潜变量，而只预测下一帧的触觉潜变量**，以捕捉细粒度接触动力学。

**技术亮点：**
- **把「模态时间尺度差异」变成显式的监督设计**，而不是靠模型自己学——这是整篇最可迁移的一招，对任何视觉 + 触觉/力/音频的多模态预测模型都成立。
- **彻底去掉大生成骨干**：编码器是 ResNet-18、速度场是 MLP、求解 6 步，因此能做到 11.9 ms 延迟，足以支撑高频闭环控制。
- **公平对比下复现基线**：由于 Tactile-WAM 未开源，作者把其核心的 Tactile Asymmetric Attention 机制植入 ManiFeel 的触觉扩散策略实现中复现；并自行构造了 VITA-VT（用与 Agile-WAM 相同的融合策略给纯视觉 VITA 加触觉）。
- 基线覆盖 Diffusion Policy（纯视觉 / 视觉 + 触觉）、Tactile-WAM、VITA 与 VITA-VT。

**实验结果：** 在 **9 个仿真 + 5 个真实**接触丰富操作任务上评测，真机任务包括 Gear Assembly、Peg Insertion、Internet Cable Insertion、Internet Cable Unplugging、Power Plug Insertion——均需触觉反馈做精确对齐与修正。整体上，**在五个真机任务中相对最强基线取得 29.4% 的相对成功率提升，同时推理延迟为 11.9 ms**。论文另附各设计选择与模型组件的完整消融。

**应用场景：** 需要高频闭环的接触丰富装配（插拔、齿轮啮合、线缆插接）；算力受限、无法部署大生成骨干的边缘控制器；带触觉/力传感的精密操作平台。

**研究价值：** ⭐⭐⭐⭐（4/5）— 对「WAM 一定要靠大视频生成骨干」这一隐含假设给出了有力的反例。多视界多模态预测的设计简洁且可解释，11.9 ms 的延迟数字对真机高频控制有直接参考意义。若能在更多本体与传感器上验证泛化性会更有说服力。

### ReShoot: Generative Visual Domain Randomization of Recorded Robot Demonstrations for Visuomotor Policy Learning

**链接：** https://arxiv.org/abs/2609.19661

**作者 / 机构：** Chiyoung Kim, Min Sung Choi, Jinho Ju, Chanhoe Gu, Donghwan Hwang, Wonseok Choi, Woongsun Jeon, Minhyeok Lee（韩国中央大学 Chung-Ang University, Seoul）

**一句话总结：** 韩国中央大学团队提出 **ReShoot**，把仿真里成熟的 domain randomization 搬到**已录制的真实演示**上：VLM 打字幕并改写单一视觉属性，边缘条件视频生成器同时重渲染两个相机视角，超分恢复锐度，VLM 再改写指令，**动作与本体感受原封不动**——于是「换一个外观」从一次采集变为一次生成，真机换色物体成功率从 **0.0% 提到 42.9% / 47.5%**。

**研究问题：** 模仿学习得到的机器人策略高度过拟合于训练演示中的视觉条件：把黑碗换成红碗，运动学与接触动力学完全没变，策略却失效。常规补救是在每个新视觉条件下重新采集演示，但每采集一类外观就要占用机器人、受控场景与人类操作员——DROID 用了约 50 名采集者、12 个月。成本由**场景多样性**而非演示条数驱动，而一次采集布设只覆盖很窄的外观范围。核心问题是：**能否在不重新采集的前提下，让一条已执行轨迹产生出具有新外观、且动作标签仍然正确的训练样本？**

**核心方法：** 给定录制演示 τ = (ℓ, {(oᶠ_t, oʷ_t, s_t, a_t)})，ReShoot 产出 τ̃ = (ℓ̃, {(õᶠ_t, õʷ_t, s_t, a_t)})，其中 õ = G(c̃, E(o))：① **VLM 字幕与属性编辑**：为场景生成描述，并只改一个属性（背景、物体颜色或表面材质）。② **边缘条件视频生成**：用 HED 边缘图 + ControlNet 条件化 **Wan2.2-T2V-A14B**，832×480、UniPC 采样 30 步、guidance 3.0、结构条件权重 1.1 并保持到去噪 95%（真机数据边缘更密，取 1.0 且 80%），**同时重画第三人称与腕部两个视角**。③ **超分**：FlashVSR 一步上采样到 1024×1024 再重采样到 256×256。④ **指令改写**：VLM 把指令 ℓ 改写为与画面一致的 ℓ̃。动作 a_t 与本体感受 s_t 完全沿用录制值，因此标签就是机器人真正执行过的动作。

**技术亮点：**
- **把生成模型的角色限定为「渲染器」而非「规划器」**：与 UniPi / AVDC / DreamGen 通过推理反推动作标签不同，ReShoot 用边缘条件把生成器约束在录制的运动上，标签零噪声。
- **与 ROSIE / GenAug / CACTI / RoboAgent / RoboEngine 的差别清晰**：前者多为逐帧修补或局部重绘，ReShoot 整段重渲染且保持多视角一致。与 Cosmos-Transfer1 相比，它的目标不是视频世界模型本身，而是以生成替代渲染、并保留标签。
- **固定训练预算下的三重对照**：Rec（仅录制）/ Mix（各一半）/ Gen（仅重渲染），三种策略跑相同的参数更新量，把「数据内容」从「训练量」中干净地分离出来。
- **量化了重渲染保留什么、改变了什么**（结构保持度与外观变化幅度），并单独评了 Gen-only 训练的表现。

**实验结果：** 基准为 LIBERO 四个 suite（Spatial / Object / Goal / Long）与 **LIBERO-Plus**（沿布局、视角、初始状态、指令、光照、纹理、传感器噪声七个维度扰动）；录制数据为 OpenVLA 使用的 1,693 条 LIBERO 训练 episode，重渲染数据为 1,000 条（每条一个变体，suite 与任务比例与录制集一致）。**LIBERO 上 Mix 96.5% 与 Rec 96.9% 基本持平**，而 **LIBERO-Plus 上从 82.3% 提升到 85.5%（+3.2 分）**。真机上（两个平台，分别使用 43 条与 100 条既有演示），**换色物体成功率从 0.0% 提升到 42.9% 与 47.5%**，同时原录制外观下的性能保持。

**应用场景：** 已积累大量演示、但部署环境外观多变的团队；无法反复占用真机做采集的低成本迭代；任何需要提升视觉鲁棒性又不希望牺牲原分布性能的场景。

**研究价值：** ⭐⭐⭐⭐（4/5）— 这是一条非常务实的路线：不追求生成新技能，只把「外观」这一维度从采集成本中剥离。+3.2 分的 LIBERO-Plus 提升看着不大，但真机上 **0.0% → 42.9%/47.5%** 是从「完全不可用」到「可用」的跃迁，且原分布不掉点——这才是工程上真正关心的指标。局限是重渲染质量受限于当前视频生成模型在长时序与手部区域的一致性。

### GAVEL: Graph World Models for Verified and Efficient Long-Horizon LLM Task Planning

**链接：** https://arxiv.org/abs/2609.19315

**作者 / 机构：** Ruiyang Wang, Hao-Lun Hsu, Swarajh Mehta, Jiwoo Kim, Zhihao Dou, Miroslav Pajic（论文未在 arXiv 页面标注机构）

**一句话总结：** 作者提出 **GAVEL**，用一张**显式图世界模型**为 LLM 长程规划做校验与修复：图中记录物体关系、动作前置条件与效果，以及对未观测物体位置的概率信念；能在执行前预测 LLM 生成动作的后果、检测违规并就地修复，只把需要语义推理的错误留给 LLM 重规划，使 Qwen3-8B 在 BEHAVIOR-1K 上的单任务成功率从 **41.2% 提到 91.8%**。

**研究问题：** LLM 为长程机器人规划提供了灵活接口，但生成的计划常常不尊重本体约束、无法从规划错误中恢复、也难以在部分可观测下有效推理。关键困难在于：失败往往是「执行到一半才发现」，而此时回滚代价极高；同时并不是所有错误都需要调用昂贵的大模型重规划——大量违规其实可以从世界模型直接推出修正。核心问题是：**如何把「后果预测—违规检测—分级修复」做成一个显式、可审计的中间层，从而既提升可靠性又降低对大模型调用次数的依赖？**

**核心方法：** ①**显式图世界模型**：节点与边编码相关物体关系、每个动作的前置条件与效果，以及对未观测物体位置的**概率信念分布**。②**执行前后果预测**：对 LLM 生成的每个动作，先在世界模型里推演其后果。③**分级修复**：检测违反前置条件或效果的动作；**若修正可直接由世界模型推出，就本地修复**；只有当错误需要语义推理时才保留 LLM 重规划——这一分层是效率与可靠性双重收益的来源。④**分布信念推理**：面对多任务指令，对可能的物体位置分布做推理，据此重排剩余子任务、最小化期望搜索代价。

**技术亮点：**
- **把「什么时候该调用 LLM」变成一个可判定的规则**，而不是靠启发式频率或人工阈值——这是 harness 类工作里少见的明确分工。
- **概率信念而非确定假设**：对未观测位置维持分布，天然处理部分可观测，且能直接用于期望代价优化。
- **同时在紧凑模型与前沿托管模型上评测**，用以区分「改进来自 harness」还是「改进来自模型能力」——论文的结论是改进主要来自 harness，这一论证方式很扎实。
- 评测规模大：BEHAVIOR-1K 上 **100 个单一长程任务 + 500 条多任务指令**。

**实验结果：** 在 BEHAVIOR-1K 上，使用 **Qwen3-8B** 时，GAVEL 把**单任务成功率从 41.2% 提升到 91.8%**，把**多任务成功率从 19.9% 提升到 92.6%**。与静态变体相比，**分布信念推理还把移动距离降低了约 5.4%**。论文指出这些改进在紧凑模型与前沿托管 LLM 上均成立，说明收益主要来自显式图世界模型这一 harness 层。

**应用场景：** 家庭服务机器人的长程任务规划；部分可观测下的物体搜索与顺序决策；需要可审计、可解释规划（能给出「为什么这个动作不可执行」）的安全敏感场景。

**研究价值：** ⭐⭐⭐⭐（4/5）— 在 LLM 规划大热的当下，这篇难得地给出了「世界模型放在 LLM 之外」这一立场的强证据：41.2% → 91.8% 的幅度，且明确论证收益不来自模型能力。局限是图世界模型本身仍需人工/半自动构建，跨场景扩展性有待观察；另外论文未在 arXiv 页面标注机构。

### Beyond Patch Removal: Persistent Adversarial Effects in Vision-Language-Action Policies

**链接：** https://arxiv.org/abs/2609.19669

**作者 / 机构：** Enhao Wu, Fusen Guo, Yuxin Cao（UNSW Sydney、UNSW Canberra、National University of Singapore）；Ziyang Lyu, Lin Li, Wei Song（Southern Cross University、Griffith University）

**一句话总结：** 新南威尔士大学、新加坡国立大学等团队指出，针对 VLA 策略的对抗补丁会造成两类效应——补丁存在时的**即时动作破坏**，以及补丁移除后仍然残留的**持续状态效应**；他们提出状态恢复协议把两者分离，发现五个动作块之后仅 **36.2%** 的 episode 仍可恢复，而同等动作误差量级的非对抗对照是 **89.9%**。

**研究问题：** 现有对抗鲁棒性评测大多关注「攻击全程存在」的情形，无法区分即时破坏与撤除后的持续影响。而后者对运行时防御尤其关键：**检测到或移除扰动，可能并不足够**——若干预发生在策略已进入低可恢复状态之后，损害已经造成。但「撤除后恢复率更低」本身并不能直接归因于对抗优化：它也可能只是遮挡、更大的动作误差或方向性持续偏差的结果。核心问题是：**优化过的对抗补丁，是否会把 VLA 策略推入比「经过匹配的、同等强度的非对抗扰动」更难恢复的状态？**

**核心方法：** ①**状态恢复协议（state-restoration protocol）**：在选定的动作块边界处，把仿真器恢复到不同扰动条件下所达的状态，移除补丁，然后用**完全相同的剩余步数预算**恢复同一冻结策略的执行。②**四组对照**：clean、random-patch（同尺寸同锚点、仅像素内容随机）、**deviation-matched**（复现对抗者的动作误差量级）、**fixed-direction**（再额外复现方向持续性），从而把持续对抗效应从遮挡、扰动幅度、方向持续偏差三种解释中分离出来，并把差值定义为 **adversarial excess**。③**恢复适配器**：在攻击诱导状态上训练一个概念验证型适配器，研究干预延迟对可恢复性的影响。④**修正 LIBERO 状态恢复保真度的三个问题**：标准快照会漏掉 Panda 夹爪内部控制器指令、恢复边界处的观测、以及决定夹具放置与渲染的任务/可视化变量——前者可使恢复后首个归一化动作变化 0.148，后者可造成最大 198/255 的像素差异。

**技术亮点：**
- **评测范式本身是贡献**：把「撤除后还能不能救回来」变成可量化、可对照的指标，且用四组匹配对照堵住了三种替代解释。
- **发现并修正了 LIBERO 状态恢复的保真度缺陷**，并给出一致性校验方法——这类基础设施工作对整个社区都有用。
- **同时验证非分块解码**：除 OpenVLA-OFT（八步动作块、20 Hz，五个块 = 2 秒闭环控制）外，还在自回归离散动作的 base OpenVLA 上做遮挡匹配对比，证明效应不是分块动作解码特有的。
- 评测与恢复训练使用**完全不共享的初始状态**，避免泄漏。

**实验结果：** 使用 EDPA 攻击（50×50 像素补丁，5% 面积比，同时施加于第三人称与腕部视角），在 LIBERO-Long 与 LIBERO-Goal 上评测冻结的 OpenVLA-OFT：**五个动作块之后，仅有 36.2% 的 episode 仍可恢复**，而 deviation-matched 对照为 **89.9%**、fixed-direction 对照为 **87.0%**。在攻击诱导状态上训练的恢复适配器，若在**一个动作块后**激活，可把 LIBERO-Long 上的恢复率从 **7.7% 提升到 47.4%**；但**干预延迟越长，可用的恢复余量急剧减少**。

**应用场景：** VLA 策略的运行时防御设计（检测 + 移除 + 恢复的完整链路）；对抗鲁棒性评测基准；对干预时延敏感的机器人安全系统。

**研究价值：** ⭐⭐⭐⭐（4/5）— 8 页短文但信息密度很高。核心结论「**移除补丁 ≠ 恢复安全**」对任何做 VLA 部署安全的人都是一记提醒，而 36.2% vs 89.9% 的对照设计让这个结论站得住。恢复适配器 7.7% → 47.4% 也给出了一线希望，但论文诚实地指出效果强依赖于干预延迟——因此防御必须与响应速度联合评估。

### RetireOPD: Self-Retiring On-Policy Distillation for Agentic Reinforcement Learning

**链接：** https://arxiv.org/abs/2609.20784

**代码：** https://github.com/ZJU-REAL/SDAR

**作者 / 机构：** Yan Yu, Zhengxi Lu, Yizhou Liu, Yichen Pan, Aozhe Wang, Qipeng Chen, Wenqi Zhang, Weiming Lu, Yongliang Shen（浙江大学）；Hua Yang, Qianglong Chen（阿里巴巴集团）

**一句话总结：** 浙江大学与阿里团队提出 **RetireOPD**：先把「带特权技能的教师」解耦并用环境奖励单独优化，再让学生同时接受 RL 与 on-policy 蒸馏（OPD）训练；关键在于 **Adaptive Retirement（自适应退休）**——学生一旦与教师差距停止缩小且达到教师成功率的既定比例，就自行「让教师退休」，此后纯用 GRPO 继续训练，从而超越了它自己的教师。

**研究问题：** 多轮 agent 用 RL 训练时每条轨迹只有一个标量奖励，于是自 on-policy 蒸馏（OPD）被引入，用带特权任务技能的自我教师提供稠密的 token 级监督，让无技能学生内化这些技能。但这一配方在 agentic 任务上被两个发现削弱：① **仅有特权信息并不总能造出可靠的教师**；② **教师监督的收益是分阶段的**（早期有用、后期可能变成束缚）。核心问题是：**能否让训练过程自行判断「教师什么时候该退场」，而不是依赖人为预设的蒸馏调度？**

**核心方法：** ①**解耦的技能条件教师**：不再把教师与学生当作同一策略的两个上下文，而是用环境奖励单独训练一个 skill-conditioned 教师，先保证教师本身可靠。②**RL + OPD 联合训练学生**：学生同时接受 GRPO 的轨迹级奖励与教师的 token 级监督。③**Adaptive Retirement**：监控学生与教师的差异（discrepancy）——一旦差异停止缩小、且学生达到教师成功率的既定比例，就**移除 OPD 项，仅用 GRPO 继续训练**。这一步替代了常见的蒸馏权重退火，因为它由训练动态本身触发。

**技术亮点：**
- **把「教师不可靠」从隐含假设变成待解决问题**：先单独用环境奖励优化教师，再谈蒸馏——顺序上的这一改动是整篇的方法支点。
- **退休准则是可判定的**：差异停止缩小 + 达到目标成功率比例，两个条件都可在线监测，不需要手工设计退火曲线。
- **断言「学生超越了自己的教师」**：在 1.5B / 3B / 7B 三种规模的全部设置上均超过其技能条件教师，这在自蒸馏类方法中并不常见。
- 对照覆盖面广：Vanilla/Skill Prompt、GRPO / GiGPO / PPO / RLOO / Skill-GRPO 等 RL 方法、OPD-Skill / OPD-大模型 / OPSD 等蒸馏方法，以及 GRPO+OPD / GRPO+OPSD 混合方法。

**实验结果：** 在 **ALFWorld** 与 **WebShop** 上评测 Qwen2.5-1.5B / 3B / 7B。1.5B 上 RetireOPD 六项 ALFWorld 任务均值为 **89.8**（GiGPO 86.7、GRPO+OPD 87.5），WebShop Score **86.6**（GiGPO 83.1、GRPO+OPD 82.5）、准确率 **75.8**（GiGPO 65.0、GRPO+OPD 69.9）。3B 上 ALFWorld 均值 **93.8**（GiGPO 92.2），WebShop 准确率 **77.3**（GiGPO 69.5、GRPO+OPD 74.2）。汇总：**ALFWorld 成功率相对 RL 基线提升 14.1%–18.8%，WebShop 准确率提升 11.8%–19.0%**，且在全部设置上超过其自身的教师。

**应用场景：** 多轮工具调用 / 网页与具身 agent 的 RL 后训练；教师—学生能力接近时的持续训练（避免被弱教师拖住）；不便手工设计蒸馏退火的自动化训练流水线。

**研究价值：** ⭐⭐⭐⭐（4/5）— 「让学生自己决定什么时候不需要老师了」是个既优雅又实用的想法，且给出了可判定的触发条件与跨三种规模的完整对照。虽然主体实验在文本 agent 环境（ALFWorld / WebShop）而非具身任务，但其「分阶段的教师可靠性」结论对 VLA / 世界模型的蒸馏同样有直接启发。

### Workspace Models: Lightweight Robotic Memory via Saliency-Driven Supervision

**链接：** https://arxiv.org/abs/2609.20820

**作者 / 机构：** Nitish Dashora, Idan Shenfeld, John Marangola, Pulkit Agrawal（Massachusetts Institute of Technology）；Douglas Chen, Max Simchowitz（Carnegie Mellon University）

**一句话总结：** MIT 与 CMU 团队（CoRL 2026）提出 **Workspace Models**：把「在闭环里反复查询 VLM 总结历史」的开销**摊销**到训练时——训练时用 VLM 判断哪些当前与历史信息是完成任务所必需的，再用集合重建解码损失蒸馏成一个轻量的 **workspace token**，部署时它可以直接替代观测喂给策略；结果不仅更快，成功率反而更高：四任务均值 **91.5%**，对比 Keyframe 基线的 **66.8%**。

**研究问题：** 复杂操作任务常常需要跨长时间窗的记忆：决定动作所需的信息可能藏在此前的观测里。但今天的机器人大模型要么只看当前帧，要么只看很短的历史——因为**朴素地加长观测历史会引入泛化误差**：无关的历史帧让学到的行为容易抓住与当前动作的虚假相关，也会让模型遇到分布外的历史。数据稀缺的机器人领域尤其严重。现有方案多在部署时并挂一个 VLM 做显式语言摘要或挑选关键帧，代价是持续的高算力查询与延迟。核心问题是：**能否把昂贵的历史理解一次性摊销进一个轻量编码器，且不让性能打折？**

**核心方法：** ①**VLM 显著性标注（训练时）**：用 VLM 判断「完成任务所需的当前与历史信息」，即所谓 salient information——信息量有限但足以完成任务，同时剔除了可能损害泛化的干扰内容。②**workspace token 蒸馏**：用一个**集合重建（set-reconstruction）解码器损失**，把上述显著性信息蒸馏进一个压缩的潜表示 workspace token。③**部署时即插即用**：workspace token 可直接作为观测的替代品喂给下游策略，无需任何 VLM 闭环推理，从而把 test-time compute 摊销掉。

**技术亮点：**
- **「摊销 test-time compute」的提法很准确**：昂贵的推理留在训练期，部署期只留一个轻量编码器——这是对 VLM-in-the-loop 类工作的直接改进。
- **任务设计把记忆拆成三个正交维度**：计数（部分可观测下）、空间回忆、从过往经验做 in-context 适应，分别对应 CubeDrop（仿真，需正好放 5 个方块，已放好的会离开视野）、HalfAndHalf（真机，把 K∈{2,4} 个方块均分到两个遮挡视野的盒子）、DrawerRecall（另一机器人先把方块藏进三个抽屉之一，本策略要打开正确的那个）、BalanceBar（两次尝试抬起未知质心的横杆，需从第一次的历史推断质心）。
- **不仅更快，还更好**：论文坦承这是最令人意外的发现——Wksp 在成功率上也超过 Keyframe，并进一步归因分析失败模式。
- **失败模式分类做得细致**：把失败分为 memory 类（技能执行正确但选错模式）与 control 类（技能本身没执行好），并指出帧堆叠类方法（HistoryDP / Keyframe）记忆尚可但控制失败多，Wksp 是唯一在两者间取得平衡的。

**实验结果：** 三个仿真任务（N=100）与一个真机任务（N=20）。**延迟**：相对 VanillaDP，Wksp 约为普通 CNN 感知栈的 **1.2 倍**，而 Keyframe 约为 **5 倍**（若用 API 调用 VLM 则更糟）。**成功率**：Wksp 在全部四个任务上均为最高，跨任务均值 **91.5% ± 2.2**，显著领先次优基线 Keyframe 的 **66.8% ± 3.2**；该优势在仿真与真机上同样成立。失败模式分析显示：VanillaDP 几乎全是记忆错误（Bar 88% / Drawer 71%），HistoryDP 与 Keyframe 的帧堆叠结构会在训练时造成**输入混叠（aliasing）**，进而损害细粒度控制；给 Keyframe 的关键帧时间加入适度抖动可显著改善，但抖动过大又会因历史覆盖变稀而欠拟合。

**应用场景：** 需要跨长时间窗记忆的操作（计数、遮挡下取物、空间回忆、试错适应）；部署算力受限、无法负担 VLM 闭环推理的机器人平台；希望把历史理解与实时控制解耦的分层系统。

**研究价值：** ⭐⭐⭐⭐（4/5）— 26 页、CoRL 2026，实验与归因都做得很完整。最有价值的不只是 91.5% vs 66.8% 这个数字，而是**「压缩后的潜记忆比显式关键帧选择更好」**这一反直觉结论及其机制解释（显式选帧造成输入混叠 → 控制精度下降）。这为「记忆该做成什么形式」给出了一个清晰的新答案。

## 📊 今日研究趋势

本期虽是补遗，但 8 篇论文聚成了三个彼此呼应、且都与「具身系统该怎么分层」相关的方向。

第一个方向是**「进度与状态」正在被显式地建模到策略之外**。MaskHarness-WAM 用目标掩码 + 已完成集合把「该操作哪个实例、做到哪一步了」交给一层 harness，于是底层 WAM 完全不用改，就在相同外观物体的按序操作上把 π0 的 20.0% 拉到 88.0%。GAVEL 把同一思路搬到 LLM 规划层：一张显式图世界模型负责预测后果、检测违规、就地修复，只有需要语义推理的错误才回抛给 LLM，Qwen3-8B 的单任务成功率因此从 41.2% 涨到 91.8%。两者的共同结论是：**长程任务的失败大多不是「做不动」，而是「不知道做到哪了」**；而这个信息完全可以放在一个可审计、可替换的外挂层里。值得注意的是，GAVEL 明确论证了改进来自 harness 而非模型能力——这与 MaskHarness-WAM「不重新设计底层 WAM」的立场是一致的。

第二个方向是**世界动作模型在同时做「减重」与「加模态」**。Agile-WAM 是最典型的例子：去掉大生成骨干，改用两个 ResNet-18 + 轻量 MLP 速度场，6 步 Euler 求解，换来 11.9 ms 延迟；同时它又加了一个模态——触觉，并通过**多视界预测**（视觉在更大时间偏移监督、触觉只预测下一帧）显式处理两个模态在时间尺度上的天然差异，最终真机相对最强基线 +29.4%。这条线与 MaskHarness-WAM 一起勾勒出 WAM 的演进方向：**骨干可以更小，但外部结构与监督设计要更精细**。

第三个方向是**生成模型与蒸馏在具身系统里的分工越来越清楚——前者放大数据，后者下沉能力**。ReShoot 是「放大数据」的样板：把生成模型当渲染器而非规划器，用边缘条件锁住动作，只改外观，于是真机换色物体从 0.0% 升到 42.9%/47.5%，原分布不掉点。RetireOPD 与 Workspace Models 则是「下沉能力」的两端：前者下沉的是**判断力之外的教师关系**——让学生在与教师差距停止缩小时自动「让教师退休」，避免被弱教师拖住，在 ALFWorld / WebShop 上相对 RL 提升 14.1%–18.8% 并反超自身教师；后者下沉的是**历史理解**——把训练时 VLM 的显著性判断蒸馏成一个 workspace token，部署时直接替代观测，延迟只有 Keyframe 的约 1/4（1.2× vs 5× VanillaDP），成功率反而从 66.8% 提到 91.5%。

一条贯穿全期的暗线是**「更多上下文」并不等于「更好表现」**。Workspace Models 给出的机制解释最精彩：显式关键帧选择会在训练时造成输入混叠，导致模型「记得住该开哪个抽屉，却抓不准把手」。Beyond Patch Removal 则从安全角度补上了另一半：VLA 一旦被对抗补丁推入低可恢复状态，**移除补丁也不足以恢复**——五个动作块后仅 36.2% 可恢复，而同等动作误差的对照是 89.9%；恢复适配器在一个块后介入能把 7.7% 拉到 47.4%，但延迟越长余量越少。综合起来看，无论是记忆、规划还是防御，**「什么时候介入」正在变得比「介入多强」更关键**。

## 🏆 最值得关注的 3 篇

1. **Workspace Models: Lightweight Robotic Memory via Saliency-Driven Supervision** — 它回答了一个被反复绕开的问题：记忆该做什么形式？答案反直觉——**压缩的潜 token 比显式挑选的关键帧更好**（91.5% vs 66.8%），而机制解释（显式选帧造成训练期输入混叠 → 细粒度控制退化）对整个长程操作社区都有价值。把 VLM 的推理摊销到训练时、部署时零查询的工程路径也很干净。

2. **Agile-WAM: An Agile Tactile World Action Model for Contact-Rich Robot Control** — 对「WAM 必须靠大视频生成骨干」给出了有力反例。多视界多模态预测（视觉大偏移、触觉下一帧）把模态间的物理时间尺度差异变成显式监督，简洁且可迁移；11.9 ms 延迟 + 真机 +29.4% 说明这条路能真正跑在高频闭环上。

3. **Beyond Patch Removal: Persistent Adversarial Effects in Vision-Language-Action Policies** — 8 页短文，但结论重要且证据扎实：**撤除对抗补丁 ≠ 恢复安全**。四组匹配对照（clean / random-patch / deviation-matched / fixed-direction）堵住了遮挡、误差幅度、方向持续性三种替代解释，36.2% vs 89.9% 的差距极具冲击力；恢复适配器与干预延迟的量化（一个块后介入 7.7% → 47.4%）则给出了可操作的方向。
