### AnyWorld: Factorized Egocentric World Models for Cross-Embodiment Generalization

**链接：** https://arxiv.org/abs/2608.29242

**项目主页：** https://xpeng-robotics.github.io/anyworld/

**作者 / 机构：** Cheng Chen, Jerry Bai, Jiacheng Wei, Boyu Chen, Xiaoji Zheng, Fan Wu, Minghao Yang, Tianrun Chen, Ruibo Li, Xiaoyu Yue, Xiaoyang Guo, Yixiao Ge, Guosheng Lin, Fayao Liu（南洋理工大学 NTU；新加坡科技研究局 A*STAR 高级智能与计算研究所；小鹏机器人 XPENG Robotics；浙江大学；香港中文大学）

**一句话总结：** 小鹏机器人与南洋理工等提出 AnyWorld，把一次人机交互因子化（factorize）为动作、相机、本体三个可独立重组的控制因子，让单条人类第一视角视频在无需配对人-机示范的前提下被"重拍"成任意本体、任意视角、任意场景下的机器人原生 rollout。

**研究问题：** 接触丰富的机器人经验难以规模化采集，除了数量，机器人学习还迫切需要在本体、视角与场景上多样化的经验。人类第一视角视频提供了海量物理交互，但每条视频只捕捉了"单一本体 + 单一相机轨迹 + 单一环境"下的一小片经验。现有方法要么要求配对的人-机器人示范，要么无法把人类经验迁移到不同本体——那么，一条人类视频究竟能不能变成多种机器人各自的原生经验？

**核心方法：** 把一次交互分解为三个可控因子：action controls 捕捉运动结构，camera controls 指定视角演化，target embodiment context 定义执行主体及其交互几何。这一形式化使得本体、视角、场景三个因子可以被独立重组，从而让单一模型在保留底层动力学与物体交互的前提下，生成大量机器人域经验。训练上采用大规模人类交互预训练 + 混合本体微调的两阶段范式。

**技术亮点：**
- 动作 / 相机 / 本体三因子解耦，使"同一段交互、换一个机器人重拍"成为可能
- 无需配对的人-机器人示范（unpaired），大幅降低数据门槛
- 大规模人类交互预训练 → 混合本体微调的两阶段训练范式
- 设计与真实本体上的受控干预实验来归因各因子的因果贡献，而非只报总体增益
- 相机不只是观感条件，而是与本体并列、可独立重组的世界因子

**实验结果：** 模型支持跨本体、跨视角、跨场景的可控重组。生成的数据可提升 RoboCasa GR1 桌面基准与真实 IRON 人形机器人上的操作表现。更有意思的是受控 IRON 干预：它纠正了一个虚假的完成先验（spurious completion prior），并成功建立起语言接地的空间目标选择；而只做动作校准的反事实干预无法稳定习得后者，说明动作校准与视觉重组二者缺一不可。

**应用场景：** 机器人操作数据增强与合成、跨本体策略泛化、人形机器人技能迁移、以世界模型为数据引擎的机器人学习。

**研究价值：** ⭐⭐⭐⭐⭐（5/5）— 把"相机可控视频生成"这一成熟工具有力地接到了机器人数据生产上：相机不再只是观感，而是与本体并列的可重组因子。无需配对数据的设定让它具备真实的规模化前景，而那组受控干预实验把"到底哪个因子在起作用"讲清楚了——这在世界模型类工作中相当罕见。

### Matrix-Game 3.5: Enhancing Real-Time Streaming Interactive World Models with Patch Memory

**链接：** https://arxiv.org/abs/2608.29910

**项目主页：** https://matrix-game-v3-5.github.io/

**作者 / 机构：** Runjia Qian, Zile Wang, Jihai Zhang, Kai Zou, Wei Yu, Jiaxing Li, Zexiang Liu, Yaokun Li, Fei Kang, Kaichen Huang, Mengyin An, Haobo Zhang, Biao Jiang, Jiahua Wang, Haofeng Sun, Yang Liu, Yangguang Li（Riemann Dynamics）

**一句话总结：** 在 Matrix-Game 3.0 之上提出 Matrix-Game 3.5，用零参数的 patch memory + tiled-PRoPE 做显式 3D 检索与投影相机条件化，用静动解耦的世界表征保住长程几何与主体身份，再用两阶段渐进式实时蒸馏把双向扩散模型压成少步因果生成器，实现分钟级实时交互世界生成。

**研究问题：** 交互式世界模型把视频生成从离线片段合成推向对交互式虚拟世界的持久仿真，服务于游戏、机器人、具身智能体与 XR。但稳定的长程交互生成仍然困难：模型必须同时守住场景几何、动态一致性与相机可控性，还要满足实时自回归生成的时延约束——这几项目标彼此拉扯。

**核心方法：** 三项改进。其一，统一的几何感知记忆框架：patch memory 与 tiled-PRoPE 两个组件都不引入任何可学习参数，把显式 3D patch 检索与投影式相机条件化结合起来，实现几何一致的相机控制与忠实的长程场景召回。其二，静动解耦的世界表征：分别对静态场景几何与动态主体建模，在长程生成中同时保住几何一致性与主体身份。其三，两阶段渐进式实时蒸馏框架：通过 Perceptual Flow Matching 与基于课程的 Self-Rollout DMD，把双向扩散模型转换为少步因果生成器。

**技术亮点：**
- patch memory + tiled-PRoPE 完全无参数，靠显式检索而非堆参数换取长程一致性
- 显式 3D patch 检索与投影相机条件化耦合，把相机控制建立在几何而非隐空间先验上
- 静态几何 / 动态主体分离建模，缓解长程生成中的主体漂移
- Perceptual Flow Matching + 课程式 Self-Rollout DMD 的两阶段蒸馏，兼顾感知质量与实时性
- 统一训练语料覆盖 Unreal 仿真环境、开放世界游戏与互联网视频

**实验结果：** 在长程场景召回、精确相机控制、主体一致性、prompt 驱动世界生成与稳定的实时开放世界交互上均表现强劲，可实现分钟级（minute-long）的实时交互生成。

**应用场景：** 游戏与开放世界实时仿真、具身智能体与机器人的交互式训练环境、XR 与数字孪生、相机可控的长程视频生成。

**研究价值：** ⭐⭐⭐⭐⭐（5/5）— 把"长程一致性"从堆参数改成显式几何检索，是一个工程上极为划算的答案：零额外参数换来相机可控与场景召回。两阶段蒸馏把双向教师压成少步因果学生，正是实时交互世界模型落地的关键路径。

### Motus2: A Self-Evolving General World Model for Dexterous Manipulation

**链接：** https://arxiv.org/abs/2608.30237

**作者 / 机构：** Hongzhe Bi, Zihao Zhou, Yihang Tang, Jingrui Pang, Shuhe Huang, Haitian Liu, Runqing Wang, Shuai Huang, Yichen Wang, Yiming Cheng, Ruowen Zhao, Zhenghua Li, Hengkai Tan, Xiaolong Liu, Jinhui Wan, Jiabao Liu, Min Zhao, Fan Bao, Jun Zhu（GensPI；清华大学；北京航空航天大学；北京理工大学）

**一句话总结：** 提出 Motus2，用一个共享权重的模型同时暴露策略（world-action model）、仿真器（action-conditioned world model）与评估器（value model）三个控制接口，三者耦合成"提出—预测—评估"的闭环决策-学习回路，让世界模型真正服务于策略改进而不只是预测未来帧。

**研究问题：** 通用具身智能体应当在统一系统内完成感知、预测、行动、评估与改进。世界模型在构建这类智能体上前景广阔，但现有模型通常只是在世界仿真器上外挂一个动作输出头，并没有把二者耦合进可用于策略改进的闭环决策与学习回路。

**核心方法：** 沿模型 scaling 与数据 scaling 两条轴推进。模型侧：单一共享权重模型暴露三个接口——策略提出候选动作块，仿真器预测其视觉后果，评估器对预测结果打分，三者耦合形成闭环；这一形式化用精选专家示范做动作学习，同时让失败与次优交互成为动力学建模与价值学习的证据。数据侧：从大规模单目第一视角数据推进到同步立体（stereo）第一视角数据，再用机器人轨迹与补充的人-机对齐数据做域适应。此外还研究了滑动窗口上下文的全局自回归与混合记忆扩展，并加入触觉反馈以实现接触感知控制。

**技术亮点：**
- 策略 / 仿真器 / 评估器三接口共享同一套权重，而非三个独立模型
- 失败与次优交互被显式当作动力学与价值学习的监督信号，而不是被丢弃
- 数据金字塔从单目 egocentric → 同步立体 egocentric → 机器人域适应逐级推进
- 引入触觉反馈做接触感知控制，与触觉智能方向直接相关
- 在双目视觉 + 双臂 + 双灵巧手 + 触觉的全仿生平台上完成实例化

**实验结果：** 本文为核心方法与系统报告，摘要主要呈现模型 scaling 与数据 scaling 两条路径的设计、闭环耦合机制以及全仿生平台的实例化，未列出与基线对照的量化基准数字。

**应用场景：** 灵巧操作与双臂协同、接触丰富的精密装配、世界动作模型（WAM）统一架构、可自我改进的具身智能体。

**研究价值：** ⭐⭐⭐⭐（4/5）— Motus 系列的延续之作，把"统一世界模型"从架构主张推进到"闭环自我进化"的具体机制：让失败数据进入训练回路，是具身智能摆脱纯模仿学习的一条关键路径。叠加立体视觉与触觉反馈，对做具身与触觉智能的人尤其值得跟踪。

### AdaVLA: Adaptive Step Flow Matching for Training-free Acceleration of Vision-Language-Action Models

**链接：** https://arxiv.org/abs/2608.29208

**作者 / 机构：** Sunghwan Han, Youngtae Han, Youngmin Yi（韩国西江大学 Sogang University 人工智能系；IROS 2026 已接收）

**一句话总结：** 提出 AdaVLA，一个在线、免训练的自适应加速框架：用流匹配轨迹曲率导出的置信度指标，在推理时动态减少 ODE 步数并自适应调整 MLP 剪枝比例，在 Jetson AGX Orin 上把 π₀.₅ 与 X-VLA 分别加速 1.87× 与 2.24×，成功率几乎不降。

**研究问题：** VLA 模型计算开销巨大，限制了端侧部署与对 environment 变化的实时响应。现有加速方法大多依赖微调或需要访问训练数据集——而训练数据常因隐私与专有性不可得。更关键的是，尽管基于流匹配的 VLA 已成为标准扩散式 VLA 的高效替代，现有加速工作基本只针对 VLM 的推理成本，完全没有触及流匹配推理固有的迭代 ODE 求解过程。

**核心方法：** 提出一个从流匹配轨迹曲率导出的新指标，用于在推理阶段量化动作生成的置信度。该指标驱动两件事：动态减少推理步数，以及通过高效计算的重要性评估来自适应调整 MLP 剪枝比例。整个过程在推理时在线完成，无需访问任何训练数据。

**技术亮点：**
- 首个明确瞄准流匹配 VLA 的迭代 ODE 求解过程（而非 VLM 主干推理）的加速工作
- 以轨迹曲率作为动作生成置信度的可计算代理，物理含义清晰
- 步数缩减与 MLP 剪枝比例的自适应联合调节
- 完全免训练、免训练数据，对隐私敏感与专有模型友好
- 在真实端侧硬件（Jetson AGX Orin）而非仅服务器 GPU 上评测

**实验结果：** 在 LIBERO 基准、Jetson AGX Orin 设备上，对 π₀.₅ 与 X-VLA 分别取得 1.87× 与 2.24× 加速，成功率退化可忽略；并在真实机器人任务上用 SmolVLA 进一步验证了方法的鲁棒性。

**应用场景：** VLA 端侧与嵌入式部署、实时反应式机器人控制、隐私敏感场景下的模型加速、流匹配类策略的推理优化。

**研究价值：** ⭐⭐⭐⭐（4/5）— 找准了一个被系统性忽略的盲区：流匹配 VLA 的瓶颈不在 VLM 主干，而在动作专家的迭代 ODE 求解。免训练、免数据的设定让它能直接贴到任何已部署的 VLA 上，工程价值很高。

### Temporal Forcing: 4D Representation Alignment for Vision-Language-Action Models

**链接：** https://arxiv.org/abs/2608.30643

**作者 / 机构：** Xingyu Ding, Yuzhong Zhao, Chunhai Zhao, Yinghuan Shi, Chaoyang Zhao, Yifan Zhang（南京大学；中国科学院自动化研究所；中国科学院大学）

**一句话总结：** 提出 Temporal Forcing，把 VLA 的表征对齐目标从 3D 场景几何升级到 4D 时空表征：先用历史通路（history pathway）把观测历史压缩成时序感知的隐表征，再与预训练 4D 基础模型提取的几何特征对齐，LIBERO 上达到 98.8%。

**研究问题：** 近期 VLA 方法通过与 3D 场景几何对齐提升了操作表现，但 3D 几何只刻画了"当前状态"，无法描述"它是如何演化到这里的"。缺少时间信息带来两个具体毛病：长程操作困难，以及视觉相似状态之间的观测混叠（observation aliasing）。

**核心方法：** 两步走。其一，引入 history pathway，让一个普通的 VLA 模型能够把观测历史总结为时序感知的隐表征；其二，把这些隐表征与预训练 4D 基础模型提取的几何特征对齐——4D 基础模型以时序一致的几何表征刻画不断演化的三维世界，从而让 VLA 对动态环境形成更深的理解。

**技术亮点：**
- 把表征对齐的目标从静态 3D 几何推进到时序一致的 4D 表征
- history pathway 是对 vanilla VLA 的轻量、可插拔改造
- 直接针对长程操作与观测混叠这两个 3D 对齐方法的固有短板
- 借助预训练 4D 基础模型提供监督，无需自建 4D 标注

**实验结果：** 在 LIBERO 上达到 98.8%，相比基座模型提升 2.2 个点；在一个真实物理的隐藏放置（hidden-placement）任务上，把完整任务成功率从 20.0% 提升到 43.3%。代码将公开。

**应用场景：** 长程机器人操作、视觉相似状态易混叠的任务、需要理解物体历史运动的操作（遮挡 / 放置类）、VLA 的时空表征增强。

**研究价值：** ⭐⭐⭐⭐（4/5）— "3D 对齐只给了当前帧、没给历史"这个观察切中要害。把 4D 基础模型的时序一致几何当作对齐目标，是一条清晰且可复用的技术路线；hidden-placement 上 20.0%→43.3% 的翻倍也说明它解决的确实是真问题。

### LightNav-0: Eliciting VLM Spatial Intelligence for Generalist Embodied Navigation

**链接：** https://arxiv.org/abs/2608.30935

**项目主页：** https://www.lightorigins.com/en/blog/lightnav-0 ｜ **代码：** https://github.com/lightorigins/LightNav-0 ｜ **模型：** https://huggingface.co/LightOriginsHQ/LightNav-0

**作者 / 机构：** Light Origins Team（Light Origins）

**一句话总结：** 提出 LightNav-0，一个紧凑的通用具身导航模型：用统一的 token 接口"激发"（elicit）预训练 VLM 已有的空间先验——双通道 pointing 表达与任务、场景、本体无关的空间意图，残差向量量化动作 tokenizer 再把它映射到本体专属轨迹——在全部 10 个公开导航仿真设置上取得单目最优成功率。

**研究问题：** 具身导航要求智能体把异构目标与视觉观测翻译成跨任务、跨环境、跨本体的动作。现代 VLM 其实已经编码了视觉接地、空间推理与指向所需的空间先验，但这些能力很少被直接激发用于机器人控制；现有导航系统转而依赖任务或本体专属的组件，把感知、推理与行动割裂开来，泛化能力有限。

**核心方法：** 用统一的 token 接口表达多样的导航任务：dual-channel pointing 表达与任务、场景、本体无关的空间意图；残差向量量化（residual VQ）动作 tokenizer 把该意图映射为精确的、本体专属的轨迹。再配合时序感知的视觉历史压缩、具身推理（ER）中训练、监督微调与强化学习，使单一模型同时支持指令跟随、开放词汇物体导航与视觉跟踪。导航训练语料覆盖 2K+ 场景、4K+ 小时具身导航数据。

**技术亮点：**
- 不新增任务专属预测头，而是"激发"VLM 已有的空间智能
- dual-channel pointing 把空间意图与本体解耦，天然支持跨本体
- 残差 VQ 动作 tokenizer 桥接"通用意图 → 本体专属轨迹"
- 单一模型统一指令跟随 / 开放词汇物体导航 / 视觉跟踪三类任务
- 2K+ 场景、4K+ 小时规模的导航训练语料

**实验结果：** LightNav-ER（用于初始化 LightNav-0 的具身推理 checkpoint）在 8 个具身推理基准上取得完整集最高平均分；LightNav-0 在全部 10 个公开导航仿真设置上取得单目（monocular）最优成功率。真实世界评测进一步展示了跨机器人本体、跨多样场景、对静态与动态目标的零样本泛化。

**应用场景：** 通用具身导航、开放词汇物体搜寻、视觉目标跟踪、跨本体机器人部署、服务与巡检机器人。

**研究价值：** ⭐⭐⭐⭐（4/5）— 在"空间智能"被反复讨论却少有落地范式的时候，给出了一套干净的落法：不造新头，只把 VLM 已经会的东西通过 pointing token 引出来。10/10 仿真设置单目最优叠加真实世界零样本跨本体，说服力足够。

### Flow-JEPA: Flow Matching for Robust Latent Dynamics in JEPA World Models

**链接：** https://arxiv.org/abs/2608.29029

**作者 / 机构：** Yanchen Huo, Ziying Song, Yadan Luo（南洋理工大学 NTU；昆士兰大学 The University of Queensland）

**一句话总结：** 提出 Flow-JEPA（F-JEPA），用条件流匹配替换 JEPA 世界模型中的确定性自回归预测器：以高斯分布作为流源，一次性联合生成整段未来隐状态序列，把逐点转移回归换成随机的轨迹级预测——干净观测下成功率 86%→92%，噪声条件下 67%→86%。

**研究问题：** JEPA 类架构在学习紧凑预测表征上潜力很大，LeWorldModel（LeWM）把它扩展到从像素出发、无需重建的隐空间世界建模。但 LeWM 的确定性自回归预测器通过反复单步转移生成未来状态，误差会逐步累积，并且对与任务无关的视觉扰动十分敏感。

**核心方法：** 提出条件流匹配动力学模型，以当前观测与动作为条件，联合生成一整段未来隐状态。以高斯分布作为流的源分布，使向量场在学习把受扰动的隐轨迹输运到干净未来表征的过程中，显式地"见过"这些扰动轨迹。该形式化完整保留了 JEPA 的重建无关框架，只把逐点的转移回归替换为随机的轨迹级预测。

**技术亮点：**
- 用轨迹级（trajectory-level）联合生成替代逐步自回归，从结构上抑制误差累积
- 高斯源分布天然向向量场注入扰动轨迹，等价于一种隐式的鲁棒性增强
- 完整保留 JEPA 的重建无关（reconstruction-free）优势，替换成本仅落在动力学头
- "流匹配替换确定性回归"这一改动足够干净，结论可直接迁移到其他 latent dynamics 模型

**实验结果：** F-JEPA 在干净观测下把平均成功率从 86% 提升到 92%，在噪声条件下从 67% 提升到 86%。

**应用场景：** 无重建的潜空间世界模型、机器人控制的隐动力学建模、对视觉扰动鲁棒的策略学习、JEPA 架构的动力学模块即插即用替换。

**研究价值：** ⭐⭐⭐⭐（4/5）— 一篇小而锋利的工作：噪声条件下 67%→86% 的 19 个点增益，直接证明了"确定性回归 → 随机轨迹级生成"这一替换的价值。对任何在用 latent dynamics / world model 的人，都是一个低成本值得一试的改动。

### RoboPhys-3D: A Comprehensive Embodied World Model Evaluation via 3D Reconstruction

**链接：** https://arxiv.org/abs/2608.28718

**作者 / 机构：** Tianyi Wang, Jiazhou Chen, Yiming Xu, Xiangyu Li, Tianyi Zeng, Chih-Hsien Chou, Ning Lu, Liang Peng, Junfeng Jiao, Christian Claudel（德克萨斯大学奥斯汀分校 UT Austin 等；66 页、12 图、55 表）

**一句话总结：** 提出 RoboPhys-3D，一个以 3D 重建为统一协议的具身世界模型（EWM）基准：让生成视频与真值视频走同一条 3D 重建流水线，从而把"重建引入的误差"与"生成引入的误差"区分开，用 50 个指标 / 18 个子维度 / 4 个层级系统检验生成 rollout 是否真的保住了底层三维场景状态。

**研究问题：** 视频世界模型正越来越多地被当作数据引擎、动作规划器与具身 AI 的仿真器。但现有 EWM 基准缺少统一的 3D 接地协议，无法判定生成的 rollout 究竟有没有保住底层三维场景状态、能不能转成可执行动作。

**核心方法：** 基于 RoboTwin 2.0 构建，覆盖 50 个操作任务、4 种设置（regime）、5,000 条 episode 与 25,000 段多视角真值视频。关键设计在于：生成视频与真值视频通过同一条 3D 重建流水线处理，使重建引入的误差可以与生成引入的误差区分开来。基准把 50 个互补指标组织进四个层级的 18 个子维度：像素级保真度、3D 几何一致性、状态级理解、任务级完整性。并提出两个总分——Average Full Score（全部 50 个指标的层级平均，求全面）与 RoboPhyscore（只平均与任务成功相关性最强的指标，求紧凑任务对齐）。

**技术亮点：**
- "同一条 3D 重建流水线"的对照设计，把重建误差与生成误差解耦，是方法学上的关键巧思
- 50 指标 / 18 子维度 / 4 层级的完整评测体系，规模在 EWM 基准中少见
- 区分 Average Full Score（全面）与 RoboPhyscore（任务对齐）两种总分，各司其职
- 用与人类评测的相关性反向验证基准有效性（Pearson r = 0.9761，Spearman ρ = 0.8962）
- 明确指出感知类指标与 VLM 判分抓不到的失败模式

**实验结果：** 在四个代表性视频世界模型中，Cosmos 3 取得最高 RoboPhyscore（0.6330，为真值的 92.7%）。与此同时，状态接地与执行接地的指标揭示出大量失败，而这些失败是感知类指标与基于 VLM 的判分都无法捕捉的。RoboPhyscore 与人类评测高度一致。

**应用场景：** 具身世界模型能力评测、视频生成模型的物理正确性检验、面向执行的仿真器可信度评估、世界模型数据引擎的质量筛选。

**研究价值：** ⭐⭐⭐⭐（4/5）— 世界模型评测长期停留在"看起来像不像"，RoboPhys-3D 把它拉回到"三维状态保没保住、动作能不能执行"。同一流水线对照的设计尤其值得借鉴；而"最优模型只有真值的 92.7%，且感知指标看不见真实失败"这一结论，对整个方向的进度判断很有分量。

## 📊 今日研究趋势

2026-09-01 的 ArXiv 给出了一条清晰主线：**世界模型正在从"生成得像"转向"可重组、可闭环、可验证"**——它不再满足于预测未来帧，而是开始被当作可操控的数据生产工具、可自我改进的控制器，以及需要被严格度量的对象。

**可重组** 的一面由 AnyWorld 代表。它把一次交互拆成动作、相机、本体三个因子并允许独立重组，本质上是把"相机可控视频生成"的成熟度兑换成机器人数据的多样性——而且不需要配对的人-机示范。这一支流把世界模型从"看未来"变成了"造经验"，其意义不在生成质量，而在它绕开了真机数据稀缺这一结构性瓶颈。

**可闭环** 的一面由 Motus2 代表。它的关键不是把策略、仿真器、评估器拼在一起，而是让三者共享同一套权重并耦合成"提出—预测—评估"的回路，同时把失败与次优交互显式纳入动力学与价值学习。与之呼应，RoboPhys-3D 补上了**可验证**的另一半：用"生成视频与真值视频走同一条 3D 重建流水线"这一巧思把重建误差与生成误差解耦，直指 EWM 评测长期缺失的三维接地。Cosmos 3 只拿到真值 92.7% 的 RoboPhyscore、且感知指标看不见真实失败，说明这条路还远未走完。

第二条明显的主线是**实时性与效率**，而且蒸馏/加速同时出现在生成侧与控制侧。Matrix-Game 3.5 用 Perceptual Flow Matching 加课程式 Self-Rollout DMD 的两阶段渐进蒸馏，把双向扩散教师压成少步因果学生，换来分钟级实时交互——对世界模型而言，实时性不是优化项而是能否作为仿真环境的前提。控制侧的 AdaVLA 则指出一个被系统性忽略的盲区：流匹配 VLA 的瓶颈不在 VLM 主干，而在动作专家的迭代 ODE 求解；它用轨迹曲率做置信度、免训练免数据地在端侧拿到 1.87×–2.24× 加速。

第三条主线可以概括为**给表征补上时间维度**。Temporal Forcing 指出 3D 对齐只给了"当前状态"却没给"演化过程"，于是把对齐目标升级为预训练 4D 基础模型的时序一致几何，在 hidden-placement 任务上把成功率从 20.0% 翻倍到 43.3%；Flow-JEPA 则用条件流匹配把 JEPA 世界模型的逐点确定性回归换成随机轨迹级生成，噪声条件下 67%→86% 的 19 点增益说明"确定性 → 随机轨迹级"本身就是一个强鲁棒性来源。一个补的是时间上的**深度**，一个补的是时间上的**不确定性**，指向同一个判断：**latent dynamics 的下一步竞争，不在表征多大，而在是否显式建模了时间结构**。

最后，LightNav-0 提示了空间智能的一条务实路径：**不造新头，只激发 VLM 已有的空间先验**。dual-channel pointing 负责与本体解耦的通用空间意图，残差 VQ 动作 tokenizer 负责落到本体专属轨迹，一个紧凑模型就统一了指令跟随、开放词汇物体导航与视觉跟踪，并在 10/10 仿真设置上取得单目最优。当"空间智能"仍常被当成一个愿景词时，这种"eliciting 而非 training from scratch"的路线给出了可复制的工程答案。
