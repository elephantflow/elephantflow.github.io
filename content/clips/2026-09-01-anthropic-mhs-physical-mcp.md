## 一句话概括

Anthropic 推出硬件版 MCP——Model Hardware Standard（MHS），用标准化驱动把显微镜、机械臂、液体处理器等物理设备统一成「读/写」这类基本命令，让 Agent 能发现、理解并安全操控真实设备，把实验室硬件集成周期从数周压缩到数小时甚至数分钟。

## 核心要点

- **定位是 MCP 的「物理版本」**。MCP 是 Anthropic 2024 年 11 月推出的开放标准，被称作「AI 领域的 USB-C 接口」，打通模型与 GitHub、Slack、本地文件系统、数据库等软件环境；MHS 把同一套规范升维到物理硬件、传感器、嵌入式系统和测试设备。MHS 的开发始于 Anthropic 与霍华德·休斯医学研究所（HHMI）Janelia 研究园区的合作，目前是研究预览版。
- **核心机制是标准化驱动程序**。它在操作系统和硬件之间做翻译，用一组基本命令（读：获取温度；写：设置温度）统一接口，设备以标准格式被发现和跨网络互发现——不再需要为每对设备写定制「翻译」程序。
- **最有意思的设计：自然语言标签 + 自动生成的设备参考文件**。设备的物理特性（比如机械臂的重量，直接关系安全操作）过去大多躺在纸质手册、用户电脑里，或者干脆是老师傅的隐性知识。MHS 驱动允许用户用自然语言录入这些标签（可以自己写，也可以跟 Agent 聊天、由 AI 主动询问硬件配置），然后自动生成一份参考文件，说明这台设备能测什么、能调什么、强制执行哪些安全限制——这是让 Agent 安全操作**从未见过的设备**的关键。
- **三种控制机制**：MCP、命令行、代码文件（API），可协同工作，一行代码编排多个设备。遇到长时间运行或超出在线推理速度的任务，Agent 把驱动命令串成代码文件交给设备自行执行，不必每一步都推理。
- **观察到的行为**：Anthropic 发现 Claude 调激光器时「如同科学家一般充满探索性」——调整参数、用摄像头观察结果、评估光斑如何移动、反复试验以理解事件的因果顺序，最后把学到的东西打包成一个确定性校准脚本，让整个流程变成一条单独的命令。
- **生态已经不小**：AWS（通过 Strands Robots）、Automata、Danaher、Doosan Robotics、MBF Bioscience（为神经科学显微镜软件 ScanImage 开发驱动）、QIAGEN、Tecan、Universal Robots 等厂商在设备内置 MHS 支持；早期采用者包括 Hugging Face（正在给机器人库 LeRobot 加支持）和 Raspberry Pi。
- **局限说得很直白**：Claude 靠文本和图像学习物理世界，空间与物理推理能力有限，仍需专家监督——比如处理蛋白质样本时，基因泰克的研究人员得引导它识别出「样本起泡」是物理故障而非软件错误，只能靠物理手段修正。另外 MHS 目前无法兼容缺少编程接口的硬件，开源前还要继续完善。

## 金句

> 大语言模型，现在真的长出手了。

> 它使每个设备都能以标准格式被发现，从而使设备和智能体能够相互发现并跨网络通信，而无需在两者之间使用定制的「翻译」程序。

> 迄今为止，这些信息大多存储在纸质手册、用户电脑或作为隐性知识。

> 许多开发者已经在使用 Claude Code 来操作单个物理设备。
